# Ponytail uninstall safety: real-browser acceptance

**PASS — 2026-09-05, release candidate for 0.2.5.**

## Environment

- Existing isolated canary at port 3082, official DSH 0.1.2-rc.1. No replacement server.
- Playwright with Google Chrome, desktop viewport 1440×1050.
- Built Host and client bundles from the uninstall-safe implementation.
- A dedicated test workspace and ordinary conversation; real model responses, no model mock and no tool calls.
- Production on port 3080 was not restarted or modified during acceptance.

Historical command results and system-prompt snapshots intentionally remain visible after uninstall; they are not evidence of an active plugin.

## Scope and evidence handling

The final canary state is running with Ponytail uninstalled. This is acceptance of the local 0.2.5 candidate, not a claim that previously published 0.2.4 logs are already safe. Old logs still require the documented opt-in migration.

Local screenshots, raw test logs, profile backups and browser drivers were retained outside version control. Screenshots can contain unrelated sidebar titles, so they are deliberately not published. Temporary browser credentials were deleted. Initial browser selector and RPC argument mismatches were corrected; final results above are backed by both GUI observations and persisted-event assertions.

Not covered: physical mobile devices, complete subagent lifecycles, or automatic migration of old release logs.
