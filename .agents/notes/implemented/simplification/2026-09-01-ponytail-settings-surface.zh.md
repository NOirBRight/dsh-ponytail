# Agent Note: Ponytail 设置保持常用界面聚焦

Status: implemented

[English](2026-09-01-ponytail-settings-surface.md) | 中文

## 问题

Ponytail 设置卡暴露了启动提示和子 Agent 匹配器控件，尽管常用的 DSH 路径只需要选择新会话的默认模式。这些额外控件让插件卡变长，并且重复了不会改变运行时约定的高级兼容配置。

## 决策

插件设置卡只暴露 `defaultMode`。卡片默认折叠，用户点击后才展开；桌面和移动版设置界面共用同一个响应式设置面板。

`quietStartup` 仍保留在 Host 设置 schema 和全部配置层中，以兼容既有配置，但默认值改为 `true`，不在设置卡显示。`subagentMatcher` 同样继续通过环境变量或上游配置读写，以保留既有部署的继承策略。Host 仍记录模式事件、应用父会话继承，并在高级配置显式关闭 quiet startup 时渲染启动覆盖层。

assembled Host 快照是发布前的无密钥检查，覆盖默认设置、会话事件、已注册技能和模型可见的 Ponytail 策略。

## 备选方案

**在卡片中保留全部控件。** 否决，因为启动提示默认隐藏，子 Agent 匹配是高级兼容选项；把两者放在常用路径会掩盖大多数用户真正需要的唯一设置。

**从 schema 中删除兼容字段。** 否决，因为既有上游配置和环境变量必须继续解析，不能要求迁移或静默丢失。

**新增仅桌面版的设置面板。** 否决，因为 DSH settings slot 已提供桌面与 dsh-mobile 共用的响应式界面。

## 后果

默认设置流程在桌面和移动版都更短且一致。高级用户仍保留旧配置入口；无密钥 assembled 快照会在发布前发现默认值和模型可见策略的变化。
